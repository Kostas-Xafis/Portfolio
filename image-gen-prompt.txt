HOW TO USE
----------
1. Copy ONE "Prompt:" paragraph (it is fully self-contained) into your
   image generator of choice (Midjourney, DALL-E, Flux, Ideogram, ...).
2. Generate at 16:9 (1200x675) or wider. Keep the main subject centered:
   the detail pages crop the same image to a 2:1 banner.
3. Save the result as the suggested filename in src/assets/covers/
   (webp recommended, png/jpg also supported).
4. Add the frontmatter line  cover: <filename>  to the matching content
   file — ideally BOTH the en- and el- versions, or the other language
   will keep showing the placeholder.
5. Entries you skip keep the styled placeholder automatically — nothing
   breaks, so generate only the ones you like.

SHARED VISUAL IDENTITY
----------------------
Every prompt below bakes in the site's design language so the covers
feel like one set: near-black background (#0b0b0c), deep slate surfaces
(#131315), a single warm golden-amber accent (#d2a24f), high contrast,
minimal composition with generous negative space, soft cinematic glow,
and no text or logos (the UI adds labels and icons where needed).

The only intentional exception is "firecast-lam", which allows a muted
ember-orange to carry the wildfire theme.
